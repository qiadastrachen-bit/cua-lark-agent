### 问题1: VLM 429限流 (TPM配额耗尽)

**现象**:
- 多次运行E2E测试，Step 04 VLM定位持续返回429错误
- 错误信息: `TPM 限流 (429)，等待 135s 让配额恢复...`
- 所有重试均失败

**原因分析**:
- VLM API有TPM (Tokens Per Minute) 配额限制
- 短时间内多次调用VLM导致配额耗尽
- 预热等待30s后仍不够恢复配额

**解决方案**:
- 降低重试次数: `MAX_VLM_RETRIES: 2→1`
- 降低定位重试: `MAX_LOCATE_RETRIES: 2→1`
- 延长预热等待: `10s→30s`
- **最终方案**: 使用固定坐标绕过VLM调用 ⭐

### 修复1: 恢复 `validate_coordinates()` 过渡区修正

**文件**: `D:/feishu-cua-challenge/ops/step_04_click_first_result.py`

**恢复的代码**:
```python
def validate_coordinates(x, y, auto_adjust=True):
    """基本坐标合理性检查 + 过渡区自动修正"""
    screen_w, screen_h = pyautogui.size()
    
    # 基本边界检查
    if x < MARGIN or x > screen_w - MARGIN or y < MARGIN or y > screen_h - MARGIN:
        return False
    
    # Y坐标检查：VLM经常把Y算偏高（点到标签栏而非结果列表）
    min_y = int(screen_h * 0.10)   # ~160px，低于此直接拒绝
    warning_y = int(screen_h * 0.18) # ~288px，此值以下可能是标签栏区域
    
    if y < min_y:
        return False
    elif y < warning_y:
        if auto_adjust:
            y_adjusted = y + 35  # ⭐ 关键修正：Y坐标向下调整35px
            return (True, x, y_adjusted)
    
    return True
```

**为什么要+35px**:
- VLM返回的坐标经常在标签栏区域 (y=202左右)
- 实际第一条结果在标签栏下方 (y=237左右)
- 35px是经过多次实测得出的最佳修正值

## 💡 经验总结

### 技术经验

1. **Git版本控制的重要性** ⭐⭐⭐
   - 代码莫名其妙出问题，第一反应是 `git diff`
   - 找到了被删除的坐标修正逻辑，这是今晚最大的突破
   - 以后每次改代码都要commit，方便回溯

2. **VLM API配额管理** ⭐⭐
   - TPM (Tokens Per Minute) 配额很容易耗尽
   - 需要合理控制重试次数和等待时间
   - 固定坐标方案是绕过限流的有效手段

3. **坐标修正逻辑的设计** ⭐⭐⭐
   - VLM返回的坐标经常偏高（Y坐标偏小）
   - 过渡区自动修正 (y+35) 是非常有效的策略
   - 需要同时处理 `validate_coordinates()` 和 `adjust_if_transition_zone()` 两个函数

4. **OpenCV模板匹配的局限** ⭐
   - 对UI变化非常敏感
   - 大分辨率截图容易导致OOM
   - 应该作为VLM失败后的兜底方案，而不是主要方案

5. **固定坐标方案的优劣势**
   - ✅ 优势: 快速、稳定、不依赖外部API
   - ❌ 劣势: 飞书窗口位置变化会导致点击失败
   - 🤔 建议: M2演示用固定坐标，M3再优化成VLM智能定位

```python
def validate_coordinates(x, y, auto_adjust=True):
    """基本坐标合理性检查 + 过渡区自动修正"""
    screen_w, screen_h = pyautogui.size()
    
    # 边界检查
    if x < MARGIN or x > screen_w - MARGIN or y < MARGIN or y > screen_h - MARGIN:
        print(f"  ⚠️ 坐标太靠近屏幕边缘: ({x}, {y}), 屏幕尺寸: {screen_w}x{screen_h}")
        return False
    
    # Y坐标检查：VLM经常把Y算偏高（点到标签栏而非结果列表）
    # 搜索框+标签栏区域大约在 y=0~200（2K屏），搜索结果列表从 ~200 开始
    min_y = int(screen_h * 0.10)   # ~160px，低于此直接拒绝
    warning_y = int(screen_h * 0.18) # ~288px，此值以下可能是标签栏区域
    
    if y < min_y:
        print(f"  ⚠️ Y坐标 {y} 太小（< {min_y}px），可能指向搜索框或标签栏")
        return False
    elif y < warning_y:
        print(f"  ⚡ Y坐标 {y} 处于过渡区（< {warning_y}px），自动向下修正")
        if auto_adjust:
            y_adjusted = y + 35
            print(f"  🎯 自动修正: ({x}, {y}) → ({x}, {y_adjusted})")
            return (True, x, y_adjusted)
        else:
            print(f"  ⚡ 过渡区未修正，原样使用")
    
    return True
```
